How do I get temporary credentials?
Get temporary credentials

In a terminal on this computer, run this with an IAM user profile that has an access key:

aws sts get-session-token --profile YOUR_IAM_PROFILE --duration-seconds NUMBER_OF_SECONDS

Copy AccessKeyId, SecretAccessKey, and SessionToken from the response into the fields below. If your IAM user requires MFA, add --serial-number YOUR_MFA_ARN --token-code YOUR_6_DIGIT_CODE. AWS instructions ↗
