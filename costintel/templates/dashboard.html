Bring Your Own AWS Account

Start locally. Keep control.

Use your own temporary AWS profile. The collector verifies account identity and stores observations locally.

Hosted account connections are not available yet. Never paste access keys into the dashboard.

  1. Configure your AWS profile

    Use a temporary login and the repository's read-only IAM policy.

  2. Collect your first snapshot 
    python -m costintel collect --mode aws \
  --profile YOUR_PROFILE \
  --expected-account YOUR_ACCOUNT_ID \
  --region {{ view.region }} --with-metrics
  3. Run end-to-end FinOps intelligence pipeline 
    python -m costintel pipeline --mode aws \
  --profile YOUR_PROFILE \
  --expected-account YOUR_ACCOUNT_ID \
  --region {{ view.region }} --with-metrics
  4. Open your workspace 
    python -m costintel serve --mode aws \
  --account YOUR_ACCOUNT_ID \
  --region {{ view.region }}
