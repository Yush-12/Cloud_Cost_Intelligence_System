# Optional AWS billing connector

CostIntel never calls the AWS Cost Explorer API during login, inventory, or normal metric collection. AWS currently charges **$0.01 per paginated Cost Explorer API request**. The console view is free. This connector is therefore disabled by default and must be enabled separately by the operator of each deployment. Check current [AWS Cost Explorer pricing and behavior](https://docs.aws.amazon.com/cost-management/latest/userguide/ce-what-is.html) before enabling it.

To enable it, grant the connected AWS identity the read-only action in [`infra/billing-read-policy.json`](../infra/billing-read-policy.json), then set `COSTINTEL_ENABLE_BILLING=1` in the server environment. For Vercel, set the variable on the project and redeploy. No request is made merely by enabling the variable. A connected user must open **Optimization impact**, click **Request billing history**, and confirm the charge. The route requires CSRF protection and the same explicit confirmation. Do not attach the billing policy to a public or shared identity; each website user supplies their own temporary AWS credentials.

One successful click makes one `GetCostAndUsage` request at the Cost Explorer `us-east-1` endpoint. It requests up to 30 completed UTC days of `UnblendedCost`, filtered to the verified linked account ID, without grouping or extra pages. If AWS returns a next-page token, the dashboard marks the result incomplete and does not fetch another page. A database uniqueness constraint permits only one attempt per workspace and AWS account per UTC day, including failed attempts. Reconnecting with a new workspace can create a new quota; this is not an AWS account-wide spending limit.

Cost Explorer data normally updates daily. It can be estimated, may differ from the final invoice, and is **not** attributed to a specific resource by this query. It does not prove savings or an optimization's impact. The connector never executes cloud changes. Existing metrics and anomaly detection continue to work with billing disabled.
